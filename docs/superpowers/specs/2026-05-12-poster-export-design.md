# 导出海报 — 设计文档

> **日期:** 2026-05-12
> **状态:** 待实现
> **平台:** 仅微信小程序

## 1. 概述

一键将今日榜单内容生成为一套 5 张精美图片（3:4 比例），方便用户保存到相册或分享到朋友圈。

- **入口:** 个人中心页「导出海报」cell（位于「订阅管理」和「转发朋友」之间）
- **5 张图:**
  1. 今日 Top3 榜单概览
  2. Top1 案例详情
  3. Top2 案例详情
  4. Top3 案例详情
  5. 近 3 日榜单（含今天）

## 2. 架构

```
profile/index.vue 点击 "导出海报"
         │
         ▼
  PosterGeneratePage
  ├─ 加载数据（todayCases + history + caseDetail×3）
  ├─ 3 个离屏 Canvas 并行渲染
  │   Canvas A: 图1 → 图5（串行）
  │   Canvas B: 图2
  │   Canvas C: 图3 → 图4（串行）
  ├─ 进度条显示 X/5
  └─ 全部导出为 tempFilePath[]
         │
         ▼
  PosterPreviewPage
  ├─ Swiper 横滑预览 5 张图
  ├─ [全部保存] → wx.saveImageToPhotosAlbum ×5
  └─ [全部分享] → 批量分享
```

**技术选型:** 方案 B — 微信 `wx.createOffscreenCanvas` 离屏 Canvas 并行渲染。

**不涉及:** 云函数、数据库 schema 变更。数据全部来自现有 API / Pinia store。

## 4. 配色方案 — 暖调编辑金

> 经 ui-ux-pro-max 设计系统优化，目标：小红书爆款杂志风

| 角色 | 色值 | 用途 |
|---|---|---|
| 背景 | `#F8F6F1` | 暖奶油底色，替代原 `#FAFAF8` |
| 卡片 | `#FFFFFF` | 纯白卡片 |
| 标题文字 | `#1C1917` | 温暖深炭色，替代原 `#1A1A2E` |
| 正文/次要 | `#78716C` | 暖灰，替代原 `#4A4A68` / `#9B9A97` |
| 强调色 | `#E11D48` | 高级玫瑰红，替代原 `#E94560` |
| 金色 | `#CA8A04` | 复古克制金，替代原 `#F5A623` |
| 边框/分割 | `#E7E5E4` | 暖灰边框 |
| 标签背景 | `#F0EDE8` | 浅米色标签底 |

**排名徽章梯度（保持不变）：**
- 🥇 渐变：`#CA8A04` → `#E5A812`
- 🥈 渐变：`#94A3B8` → `#64748B`
- 🥉 渐变：`#C4956A` → `#A67B5B`

**特点：** 与方案 A 暖调编辑金对齐——暖而不甜、克制有品质、日系杂志高级感。

## 5. 图片规格

- **尺寸:** 750 × 1000 px（3:4 比例）
- **字体:** 系统默认（Canvas 文本渲染，不加载网络字体）
- **风格:** 暖调编辑杂志风，大面积留白，卡片式排版

### 底部品牌区（所有 5 张图统一）

手机 SVG 图标 + "精益副业案例库" 文字，居中显示于图片底部。无二维码。

## 7. 数据流

```
profile/index.vue 点击 "导出海报"
  │
  ▼ navigateTo
PosterGeneratePage (onLoad)
  │
  ├─ 1. 读取 useCaseStore().todayCases          ← 已有缓存
  ├─ 2. getHistoryPicks({page:1, pageSize:3})   ← 云函数
  ├─ 3. getCaseDetail(id) × 3                    ← 云函数（并行）
  │
  ├─ 4. 启动 Canvas 渲染
  │   createOffscreenCanvas({type:'2d', width:750, height:1000}) × 3
  │
  ├─ 5. 进度回调
  │   onProgress(completed, total) → 更新进度条
  │
  └─ 6. 全部完成 → tempFilePath[5]
        │
        ▼ navigateTo
      PosterPreviewPage
        ├─ Swiper 展示 5 张
        ├─ [全部保存] → forEach saveImageToPhotosAlbum
        └─ [全部分享] → 批量分享
```

## 8. 异常处理

| 场景 | 处理 |
|---|---|
| 今日无榜单数据 | Toast "今日暂无榜单数据"，不进入生成页 |
| 近 3 日数据不全 | 仅显示有数据的日期，不报错 |
| 单案例详情加载失败 | 该图对应位置显示灰色占位 + "加载失败"，其余图正常 |
| 某张图 Canvas 渲染失败 | 进度显示 "X/5 失败"，该图为灰色占位，其余正常 |
| 全部渲染失败 | Toast "生成失败，请重试"，留在当前页 |
| 用户拒绝相册权限 | Toast "请授权相册权限"，引导设置页 |
| 部分保存失败 | 提示 "3/5 张已保存，2 张失败" |
| 页面中途退出 | `onUnload` 清理离屏 Canvas，释放内存 |

## 9. 进度反馈

- 点击「导出海报」→ 全屏 loading 页，显示 "正在生成 0/5"
- 每完成一张更新为 "正在生成 X/5"，带进度条动画
- 全部完成 → 自动跳转预览页
- 生成失败 → 停留在生成页，显示错误详情 + 重试按钮

## 10. 测试策略

| 层级 | 内容 |
|---|---|
| **单元测试** | `usePosterCanvas.ts` — mock Canvas API，验证绘制指令序列、坐标计算、文字截断 |
| **集成测试** | 完整流程：点击 cell → 数据加载 → Canvas 渲染 → 预览页 → 保存 |
| **边界测试** | 空数据、超长标题截断、缺字段案例、弱网超时 |

## 11. 设计约束

- 仅微信小程序平台实现（`#ifdef MP-WEIXIN`）
- `wx.createOffscreenCanvas` 要求基础库 ≥ 2.16.0
- 不涉及云函数或数据库变更
- 所有数据复用现有 API（getDailyPick、getHistoryPicks、getCaseDetail）
- 设计风格对齐暖调编辑金方案（第 4 节配色），暖奶油底色 + 复古金 + 玫瑰红
